# Acoustic Metamodels Sound Analyzer
* Приложенеи с графическим интерфейсом на PyQt5 для автоматизационной генерации звуковых сигналов, их записи через измерительный тракт (микрофон/колонки) и последующего акустического анализа (расчёт спектров, фильтрация Баттерворта и вычисление потерь звукоизоляции - Transmission Loss)
---
# Основные возможности

*   **Генерация и запись сигналов (`recorder.py`):** 
    *   Поддержка непрерывных сигналов (синусоида, свип-тон, белый шум).
    *   Режим пошагового частотного сканирования (sweep) с настраиваемыми циклами измерений и паузами.
    *   Автоматическое сохранение сессий в файлы с временными метками.
*   **Спектральный анализ и фильтрация (`analyzer.py`):**
    *   Быстрое преобразование Фурье (БПФ) с применением zero-padding для повышения частотного разрешения.
    *   Цифровая фильтрация сигналов с помощью полосового фильтра Баттерворта в SOS-формате.
*   **Акустические расчеты:** 
    *   Автоматический расчет потерь передачи звука (*Transmission Loss*, в дБ) на основе сравнения опорного сигнала и сигнала, прошедшего через 3D-печатный образец.
    *   Учет корректных геометрических параметров распространения звука в измерительной ячейке.
*   **Графический интерфейс (GUI):** 
    *   Современный интерфейс на PyQt5, разделенный на удобные вкладки для управления записью и визуализации графиков.
    *   Интеграция с matplotlib для вывода спектров и сравнительных диаграмм.

# Архитектура проекта

```text
├── main.py                # Точка входа для запуска приложения
├── app_framework.py       # Главный класс приложения, связывающий GUI и логику
├── gui_main_window.py     # Описание графического интерфейса пользователя
├── recorder.py            # Модуль работы со звуковой картой (sounddevice) и генерации сигналов
└── analyzer.py            # Математическая обработка, БПФ, фильтрация и расчет TL
```

# **Требования к системе**
Для запуска проекта необходим установленный Python 3.8+ и следующие библиотеки:
* `PyQt5` (для графического интерфейса)
* `numpy` (для массивов и матричных вычислений)
* `scipy` (для фильтрации и математического анализа)
* `matplotlib` (для построения графиков спектров и TL)
* `sounddevice` (для захвата и воспроизведения звука)

# Установка и запуск
1. Клонируйте репозиторий или загрузите файлы проекта в рабочую директорию.
2. Установите необходимые зависимости через терминал:
```text
Bash
pip install PyQt5 numpy scipy matplotlib sounddevice
```

3. Запустите приложение командой:
```text
Bash
python main.py
```

# Руководство пользователя (Quick Start)
* **Вкладка «Recording» (Запись):**
   * Выберите тип сигнала (например, Chirp или Sine).
   * Задайте параметры (частотный диапазон, длительность, задержки).
   * Убедитесь, что устройство ввода/вывода (колонка и микрофон) настроено корректно, и нажмите кнопку Start для запуска серии измерений. Данные запишутся в рабочую директорию.

* **Вкладка «Analysis» (Анализ):**
   * Укажите пути к файлу с результатами эксперимента и опорному (reference) файлу.
   * При необходимости активируйте фильтрацию Баттерворта.
   * Нажмите кнопку Plot TL spectra для построения итогового графического сравнения потерь звука.
