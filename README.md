# Acoustic Metamodels Sound Analyzer
* Приложенеи с графическим интерфейсом на PyQt5 для автоматизационной генерации звуковых сигналов, их записи через измерительный тракт (микрофон/колонки) и последующего акустического анализа (расчёт спектров, фильтрация Баттерворта и вычисление потерь звукоизоляции - Transmission Loss)
---
# Основные возможности

*   **Генерация и запись сигналов (`recorder.py`):** 
    *   Поддержка непрерывных сигналов (синусоида, свип-тон, белый шум).
    *   Режим пошагового частотного сканирования (sweep) с настраиваемыми циклами измерений и паузами.
    *   Автоматическое сохранение сессий в файлы с временными метками.
*   **Спектральный анализ и фильтрация (`analyzer.py`):**
    *   Быстрое преобразование Фурье (БПФ) с применением zero-padding для повышения частотного разрешения.
    *   Цифровая фильтрация сигналов с помощью полосового фильтра Баттерворта в SOS-формате.
*   **Акустические расчеты:** 
    *   Автоматический расчет потерь передачи звука (*Transmission Loss*, в дБ) на основе сравнения опорного сигнала и сигнала, прошедшего через 3D-печатный образец.
    *   Учет корректных геометрических параметров распространения звука в измерительной ячейке.
*   **Графический интерфейс (GUI):** 
    *   Современный интерфейс на PyQt5, разделенный на удобные вкладки для управления записью и визуализации графиков.
    *   Интеграция с matplotlib для вывода спектров и сравнительных диаграмм.
